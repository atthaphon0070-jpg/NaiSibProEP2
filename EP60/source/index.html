CPU
Central Processing Unit
หน่วยประมวลผลกลาง
เก่งงานหลากหลาย
ควบคุมการทำงานโดยรวม
จัดการคำสั่งซับซ้อน
GPU
Graphics Processing Unit
หน่วยประมวลผลกราฟิก
GPU
เหมาะกับงานแบบขนาน
คำนวณหลายงานพร้อมกัน
เหมาะกับงานกราฟิกและบางงานคำนวณ
CPU = หัวหน้าทีม
คนเดียว จัดการงานได้หลายแบบคิด · ตัดสินใจ · สั่งงานเป็นขั้นตอน
GPU = ทีมงานจำนวนมาก
งานแบบเดียวกันจำนวนมาก→ ช่วยกันทำพร้อมกัน
GPU ไม่ได้เร็วกว่า CPU ในทุกงาน
ต้องดูประเภทของงาน
