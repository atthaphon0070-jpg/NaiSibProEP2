# NaiSibPro EP.45 — คนที่ออกไปได้กี่คะแนน? (ค่าเฉลี่ยเลขคณิต)

Vertical 1080 × 1920, 30 fps, H.264 / AAC. Audio-first: the seven original Thai ElevenLabs recordings drive every beat.

**Final video:** `output/NaiSibPro_EP45_Missing_Student_Average.mp4`

## Layout
| Path | What it is |
|---|---|
| `audio/` | The seven original narration files (bytes unchanged; renamed from `*.mp3.mp3`) |
| `episode.json` | Segment order, exact 5 s countdown, output name, music settings (no master gain: narration already peaks at −0.4 dBFS) |
| `source/index.html` | Page: Blue Dominant overrides of the shared engine CSS + scene containers |
| `source/math_logic.js` | Single source of truth for every number (12, 70, 840, 11, 68, 748, 92, choices, self-checks). Works in the browser and in Node |
| `source/beats.js` | Phrase cues measured in each recording (with the spoken words) |
| `source/student_group.js` | 12 rigged 2D students (sit / stand / walk / blink / expressions / silhouette), avatars, classroom set with camera |
| `source/average_dashboard.js` | Digital scoreboard: student count + average with slot-style digit changes (12 → 11, 70 → 68), pips, down-arrow, scan sweep |
| `source/scenes.js` | All eight scenes, SFX cues, safe-zone transform guard |
| `source/timeline.js` | Generated by `audio_prep.py` (measured timeline) |
| `tools/qc_scan.js` | Automated QC: safe zone on every 3rd frame, spoiler scan, first frame, frame-exact countdown, maths |
| `tools/beat_map.js` | Writes `qc/beat_map.md` |
| `qc/` | QC reports, first frame, contact sheet |
| `renders/` | Build scratch (git-ignored): timeline, narration, SFX list, mix, frames |

## Build
```bash
shared/tools/build_episode.sh EP45
```
```bash
node EP45/tools/qc_scan.js EP45
```
```bash
node EP45/tools/beat_map.js
```
`WORKERS=4` (default) parallel Chromium renderers. A full build is ~6 030 frames.

Shared-tool change: `shared/tools/audio_mix.py` gained five new SFX kinds (`digit`, `chime`, `sub`, `pen`, `room`). Existing kinds are untouched, so earlier episodes rebuild identically.
