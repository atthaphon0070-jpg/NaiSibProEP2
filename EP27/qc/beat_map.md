# EP27 beat map

Times are seconds from the start of each narration file. Phrase starts come from a 10 ms RMS pause map (EP27/tools/segment.py, -38 dBFS, 0.18 s minimum gap). The words inside each phrase come from a local Whisper-small transcription (faster-whisper, word timestamps, plus a second pass on every pause-delimited phrase); English command names (Mailings, Start Mail Merge, Select Recipients, Insert Merge Field, Preview Results, Finish & Merge, Track Changes, WordArt, Find & Replace) use Whisper's word times. The transcript was used for timing only; the narration itself is untouched.

Every visual beat in `source/index.html` reads its time from `source/beats.js` (the numbers below). "Abs" is the time in the final video, "Frame" its 30 fps frame index.
