# NaiSibPro EP.47 — คอมพิวเตอร์ 5 ประเภท ต่างกันอย่างไร? (Five Types of Computers)

**Final video:** `output/NaiSibPro_EP47_Five_Types_of_Computers.mp4`. It is 1080 × 1920 (9:16), 30 fps constant, H.264 High / yuv420p with AAC 48 kHz stereo. It runs **220.67 s (3:40.7)** across 6,620 frames.

> **Duration conflict (reported, not hidden).** The seven supplied narration files add up to 214.178 s. With the mandatory 5 s countdown that is 219.18 s, which is **39.18 s over the 180 s limit**. Leading and trailing silence across all files totals only 2.21 s, so the limit can't be met without cutting, re-voicing or speeding up the narration. None of that was done. The audio is used byte-for-byte as supplied.

Rebuild it with:

```bash
shared/tools/build_episode.sh EP47
```

Then run the QC:

```bash
node EP47/tools/qc_page.js EP47 && python3 EP47/tools/qc_media.py EP47
```

## Project layout
| Path | Contents |
|---|---|
| `audio/` | The seven original MP3s. They are byte-identical to the ZIP (SHA-256 in `qc/audio_durations.txt`); only the doubled `.mp3.mp3` extension was dropped |
| `episode.json` | Segment order, the 5 s countdown, music settings, `crf` 21 (keeps the file under GitHub's 100 MB limit) |
| `source/index.html` | Page shell + EP47 Blue Dominant theme overrides; loads the shared engine |
| `source/beats.js` | Phrase starts measured from the narration |
| `source/computer_types.js` | All educational wording: the five categories, the quiz, the four approved choices, the correct index |
| `source/environment_animations.js` | Five animated computing environments + modern server room, 3D gear (canvas), weather simulation (canvas), people seen from behind, icons |
| `source/scenes.js` | Scene timeline (`renderAt(t)` is deterministic), SFX cues, exact countdown, reveal logic |
| `tools/qc_page.js`, `tools/qc_media.py` | QC: countdown per frame, no early reveal, safe zone over moving frames, text audit, narration integrity, frame grabs from the exported MP4 |
| `qc/` | Reports and images (see `qc/QC_REPORT.md`) |
| `output/` | Final MP4 |

The `renders/` folder (frames, `mix.wav`, `timeline.json`) and `source/timeline.js` are generated by the build and git-ignored.
