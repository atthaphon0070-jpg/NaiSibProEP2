# NaiSibPro EP.42 — เน็ต 100 Mbps โหลดไฟล์ 500 MB ใช้เวลากี่วินาที?

**Topic:** Computer Studies, covering internet speed, data units and bits vs Bytes (`b` ≠ `B`).
**Final video:** `output/NaiSibPro_EP42_Mbps_vs_MB_Download.mp4` is 1080×1920 (9:16), 30 fps CFR, H.264 High yuv420p, with AAC 48 kHz stereo audio.
**Answer:** ค. 40 วินาที, because 500 MB × 8 = 4,000 Mb and 4,000 Mb ÷ 100 Mb/s = 40 s. This is a theoretical value using decimal units.

Rebuild it from the repository root:

```bash
shared/tools/build_episode.sh EP42
```

Run QC (maths, safe zone, answer-leak scan and countdown frames):

```bash
node EP42/tools/qc.js
```

## Layout
| Path | What it is |
|---|---|
| `audio/` | The seven original ElevenLabs narration files. They are byte-identical to the ZIP; only the doubled `.mp3.mp3` extension was dropped |
| `episode.json` | Segment order, the 5 s countdown, output name, music bed and mastering gain |
| `source/index.html` | Page shell and the blue-dominant theme. It overrides the shared pastel defaults for this episode only |
| `source/beats.js` | Measured phrase starts per narration file (segment-local seconds) |
| `source/data_units.js` | Every number shown on screen is derived here: 100 Mbps, 500 MB, ×8, 4,000 Mb, 40 s, 12.5 MB/s. It also holds the self-check `UNITS.validate()` |
| `source/download_engine.js` | Reusable download window with a 0/25/50/75/100 % tick bar, server→PC packet stream and speed gauge |
| `source/scenes.js` | The 8 scenes plus an animated circuit-trace background |
| `source/timeline.js` | Generated by `shared/tools/audio_prep.py` from the measured audio |
| `tools/qc.js` | Automated QC; it writes into `qc/` |
| `qc/` | QC report, beat map, durations, maths validation, safe-zone report, first frame and contact sheet |
| `EP42_HANDOFF.md` | The full handoff |

Shared files used without modification: `shared/engine/engine.js` + `engine.css` (life/easing, quiz cards, confetti, wipes, SFX registry), `shared/tools/*` (audio prep, mix, render, build) and `shared/brand/*` (logo, mascots). Earlier episodes and shared files were not changed.
